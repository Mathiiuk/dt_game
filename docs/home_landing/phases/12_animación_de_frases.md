# VESTUARIO — HOME LANDING

# FASE 11 — ANIMACIÓN DE FRASES

Estados:

```text
IDLE
ENTER
VISIBLE
EXIT
WAIT
NEXT
```

Timing recomendado:

- enter: 500–800 ms;
- visible: 2500–4500 ms;
- exit: 500–800 ms;
- espera: 300–1000 ms.

Usar:

- opacity;
- pequeño translate;
- blur mínimo;
- scale entre 0.98 y 1.

Evitar:

- bounce;
- shake;
- zoom agresivo;
- glitch.

El movimiento debe ser cinematográfico y lento.
