# VESTUARIO — HOME LANDING

# FASE 28 — BACKGROUND

Si se utiliza imagen:

- AVIF/WebP;
- responsive;
- compresión;
- tamaño adecuado.

No utilizar una imagen de 5–10 MB.

Si se utiliza vídeo posteriormente:

- poster;
- fallback;
- carga no bloqueante;
- compresión.

Inicialmente se recomienda imagen/arte ligero antes que video de fondo.
