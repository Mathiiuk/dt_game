# VESTUARIO — HOME LANDING

# FASE 25 — PUBLIC VS PRIVATE

La Home es pública.

El juego autenticado debe vivir aparte:

```text
/app
/app/dashboard
/app/plantel
/app/tacticas
/app/mercado
/app/entrenamiento
/app/partido
/app/club
/app/dt
```

El área privada:

- requiere autenticación;
- no entra en sitemap;
- no debe competir en SEO;
- debe evitar indexación accidental.
