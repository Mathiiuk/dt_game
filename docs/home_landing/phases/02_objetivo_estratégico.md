# VESTUARIO — HOME LANDING

# FASE 1 — OBJETIVO ESTRATÉGICO

## Objetivo principal

En menos de cinco segundos el visitante debe entender:

1. qué es Vestuario;
2. que es un juego de fútbol;
3. que él es el DT;
4. que puede comenzar una carrera.

## Objetivo emocional

La reacción buscada:

> “Quiero probarlo.”

## Mensaje núcleo

> **Vos sos el DT.**

CTA principal:

> **Crear mi carrera**

CTA secundario:

> **Conocer el juego**
