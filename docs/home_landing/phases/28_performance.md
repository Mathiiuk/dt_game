# VESTUARIO — HOME LANDING

# FASE 27 — PERFORMANCE

La Home debe ser extremadamente liviana.

Optimizar:

- LCP;
- INP;
- CLS;
- JavaScript;
- CSS;
- imágenes;
- fuentes.

Evitar:

- videos gigantes;
- fondos de varios MB;
- librerías de animación innecesarias;
- cinco o seis fuentes;
- JS excesivo.
