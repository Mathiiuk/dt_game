# VESTUARIO — HOME LANDING

## Contenido

- `HOME_LANDING_MASTER.md`: prompt completo de diseño, UX, SEO y desarrollo.
- `phases/`: cada fase separada para entregarla individualmente a un LLM.

## Orden

Las fases están numeradas y forman una especificación progresiva:

1. Contexto y objetivo
2. Estructura
3. Header
4. Atmosfera
5. Identidad visual
6. Tipografía
7. Hero
8-12. Sistema de frases
13-15. CTA y footer
16-18. Responsive
19-25. SEO y arquitectura
26-34. Técnica, analítica y contenido
35-38. Copy y reglas
39-42. QA
43-45. Aceptación y visión final

La Home debe mantenerse deliberadamente simple y sin scroll, mientras las páginas secundarias concentran el contenido SEO profundo.
