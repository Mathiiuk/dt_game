# FASE 8 — ENTRENAMIENTO

## Objetivo
Permitir desarrollar el plantel.

## Tipos
- Físico.
- Táctico.
- Técnico.
- Defensivo.
- Ofensivo.
- Balón parado.
- Recuperación.
- Juveniles.

## Efectos
Cada sesión modifica:
- Fitness.
- Fatiga.
- Atributos.
- Moral.
- Riesgo de lesión.

## Intensidad
- Baja.
- Media.
- Alta.

## Reglas
Más intensidad:
+ desarrollo
+ fatiga
+ riesgo

Recuperación:
- fatiga
- menor desarrollo

## Entrenamiento individual
Permitir asignar foco:
- Pase.
- Definición.
- Marca.
- Físico.
- Técnica.

## Requisito
El sistema debe evitar que entrenar constantemente sea siempre óptimo.
