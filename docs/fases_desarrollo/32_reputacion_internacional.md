# FASE 32 — REPUTACIÓN INTERNACIONAL

## Escala
Local → Nacional → Continental → Internacional → Mundial.

## Desbloqueos
- Scouts internacionales.
- Clubes extranjeros.
- Competencias internacionales.
- Selecciones.

## Cálculo
Basado en:
- Títulos.
- Nivel de competición.
- Resultados.
- Tiempo.
- Desarrollo de jugadores.

No subir reputación solamente por cantidad de partidos.
