# FASE 26 — PERSONALIDAD DE JUGADORES

## Tipos
- Ambicioso.
- Profesional.
- Líder.
- Introvertido.
- Conflictivo.
- Leal.
- Ambicioso económicamente.
- Promesa.
- Perfeccionista.

## Influencia
La personalidad modifica:
- Negociaciones.
- Entrenamiento.
- Moral.
- Respuesta a suplencia.
- Decisiones de carrera.
- Vestuario.

## Requisito
No mostrar todos los rasgos inmediatamente.
Algunos pueden descubrirse mediante observación y scouting.
