## Regla de desarrollo

No implementar todas las fases simultáneamente.

Cada fase debe:
- compilar,
- poder probarse,
- persistir correctamente,
- no romper fases anteriores,
- tener estados vacíos,
- tener validación backend,
- registrar errores,
- incluir datos de prueba cuando corresponda.
