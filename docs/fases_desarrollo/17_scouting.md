# FASE 17 — SCOUTING

## Scouts
Atributos:
- Nivel.
- Precisión.
- Especialidad.
- Países.
- Coste.

## Búsqueda
Filtros:
- Edad.
- Posición.
- Valor.
- Potencial.
- País.

## Información imperfecta
El scout puede mostrar:
`Potencial estimado: 75–88`

El potencial real permanece oculto.

## Reporte
- Fortalezas.
- Debilidades.
- Personalidad estimada.
- Valor.
- Recomendación.

## Tiempo
Un scouting profundo requiere días/semanas.
