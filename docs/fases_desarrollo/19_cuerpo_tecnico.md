# FASE 19 — CUERPO TÉCNICO

## Personal
- Ayudante.
- Preparador físico.
- Entrenador de arqueros.
- Analista.
- Scout.
- Médico.
- Psicólogo deportivo.

## Atributos
Cada miembro tiene:
- Nivel.
- Salario.
- Especialidad.
- Contrato.

## Efectos
Ejemplo:
Preparador físico nivel 3:
- Reduce fatiga.
- Mejora desarrollo físico.
- Reduce riesgo.

## Contratación
El club debe poder:
- Buscar.
- Entrevistar.
- Contratar.
- Renovar.
- Despedir.
