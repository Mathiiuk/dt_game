# FASE 5 — NIVELES DEL DT

## Objetivo
Crear progresión permanente del entrenador.

## XP
Fuentes:
- Partidos.
- Victorias.
- Objetivos.
- Ascensos.
- Títulos.
- Desarrollo de jugadores.
- Descubrimientos.
- Gestión económica.

## Niveles
1–50.

Ejemplo:
1 Novato
2 Aprendiz
3 Entrenador
4 Profesional
5 Reconocido
...
50 Leyenda.

## Cada nivel
Puede otorgar:
- Puntos de habilidad.
- Nuevos sistemas.
- Mejor negociación.
- Mejor scouting.
- Mayor reputación.

## Reglas
- Evitar crecimiento exponencial descontrolado.
- XP calculada en backend.
- No permitir otorgarse XP desde cliente.
- Mostrar progreso actual y siguiente nivel.
