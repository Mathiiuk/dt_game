# FASE 16 — AGENTES

## Perfil
Cada agente:
- Personalidad.
- Exigencia.
- Influencia.
- Relación con club.
- Cantidad de representados.

## Negociación
El agente interviene en:
- Salario.
- Prima.
- Duración.
- Cláusula.
- Rol.

## Comportamientos
Agente exigente:
- Negociación más dura.

Agente flexible:
- Más fácil cerrar.

## Relación
Buenas experiencias pueden mejorar futuras negociaciones.
