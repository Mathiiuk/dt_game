# FASE 13 — MERCADO DE JUGADORES

## Objetivo
Crear compra y venta.

## Filtros
- Nombre.
- Edad.
- Posición.
- Overall.
- Potencial.
- Valor.
- Nacionalidad.

## Ficha
Mostrar:
- Datos.
- Atributos visibles.
- Potencial estimado.
- Valor.
- Salario.
- Contrato.
- Estado.

## Oferta
Tipos:
- Compra directa.
- Cuotas.
- Bonificaciones.
- % futura venta.
- Intercambio.

## Negociación
Club vendedor:
- Acepta.
- Rechaza.
- Contraoferta.

## Reglas
El precio depende de:
- Valor.
- Edad.
- Potencial.
- Forma.
- Contrato.
- Importancia.
- Demanda.

## Mercado
Debe tener ventanas:
- Pretemporada.
- Mitad de temporada.

No permitir transferencias fuera de período salvo reglas especiales.
