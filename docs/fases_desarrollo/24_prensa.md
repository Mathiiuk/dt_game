# FASE 24 — PRENSA

## Momentos
- Prepartido.
- Postpartido.
- Mercado.
- Crisis.
- Títulos.

## Preguntas
Ejemplo:
`¿Por qué el goleador estuvo en el banco?`

## Respuestas
Cada respuesta tiene intención:
- Táctica.
- Protección.
- Honestidad.
- Presión.

## Consecuencias
Puede afectar:
- Vestuario.
- Hinchada.
- Prensa.
- Directiva.

## Regla
Las respuestas no deben tener siempre una opción "correcta".
