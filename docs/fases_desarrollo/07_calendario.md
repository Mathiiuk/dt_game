# FASE 7 — CALENDARIO

## Objetivo
Introducir el paso del tiempo.

## Semana
Ejemplo:
Lunes: entrenamiento.
Martes: entrenamiento.
Miércoles: descanso.
Jueves: táctica.
Viernes: entrenamiento.
Sábado: concentración.
Domingo: partido.

## Avance
Botón:
`Avanzar día`.

Antes de avanzar:
- Mostrar eventos.
- Confirmar decisiones pendientes.
- Aplicar entrenamiento.
- Actualizar fatiga.

## Calendario
Debe mostrar:
- Partidos.
- Entrenamientos.
- Lesiones.
- Suspensiones.
- Eventos.
- Fechas de mercado.

## Regla
El tiempo solo avanza mediante acciones controladas del usuario, salvo procesos internos explícitos.
